Entry for the make.fun bounty "One Word From Grandma" ($5).

## What it is

`main.py` writes exactly one word to `/output/entry.txt`: the word a
grandma would text about AI. The word is **knowitall** — warm, a
little baffled, and funny in a single word: the machine that knows
everything, summed up the way a grandma would text it to her
grandchild. No sentence, no explanation, no punctuation tricks.

## How the program works

Running the program creates `/output` if needed and writes the word
as UTF-8 to `/output/entry.txt`. There is no network access, no
input, and no randomness: the output is always the same one word,
9 characters, inside the 1–30 character gate.
